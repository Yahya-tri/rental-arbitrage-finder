# Rental Arbitrage Finder — Ready Build

## What it is
A browser-based Streamlit app for screening rental-arbitrage opportunities in the DMV.

## Current features
- Washington, DC / Silver Spring / Baltimore benchmarks
- Candidate property CSV import
- Monthly/annual revenue and profit estimate
- Break-even occupancy
- Startup cash estimate
- 0–100 deal score
- Bad / conservative / base / strong stress tests
- Lease / landlord / HOA / local-rule checklist
- DC caution banner

## Important
This build deliberately does not scrape Zillow or Airbnb. Use permitted data, exports, APIs, or manually entered comps, and verify all licensing and lease restrictions before signing.
